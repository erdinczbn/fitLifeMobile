# FitLife Mobil (İdeal Kilo & Sağlık Hesaplayıcı)

Android platformu için Java ile geliştirilmiş; kullanıcıların vücut kitle indeksi (BMI), ideal kilo, vücut yağ oranı ve yağsız vücut kütlesi analizlerini gerçekleştiren yerel (native) bir mobil sağlık hesaplama uygulaması.

## Özellikler
- **Vücut Kitle İndeksi (BMI):** Boy ve kilo parametrelerine göre anlık kategori ve sağlık durumu analizi.
- **İdeal Kilo Hesaplama:** Cinsiyet ve boy uzunluğuna göre kişiye özel ideal kilo tahmini.
- **Vücut Kompozisyonu Analizi:** Vücut yağ oranı (BFP) ve yağsız vücut kütlesi hesaplamaları.
- **Kullanıcı Dostu Arayüz:** Hızlı veri girişi ve anlaşılır sonuç paneli.

## Kullanılan Teknolojiler
- **Programlama Dili:** Java
- **Geliştirme Ortamı:** Android Studio
- **Yapılandırma & Derleme:** Gradle (Kotlin DSL)
- **Minimum SDK Desteği:** Android API 23+
